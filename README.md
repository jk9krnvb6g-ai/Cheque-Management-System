# ระบบจัดทำและพิมพ์เช็ค (Cheque Management System)

ระบบบริหารจัดการ ออก และพิมพ์เช็คราชการและองค์กร (รองรับธนาคารกรุงไทย KTB, ธ.ก.ส. BAAC, ธนาคารออมสิน GSB และเพิ่มธนาคารกำหนดเองได้) ออกแบบมาสำหรับการทำงานที่แม่นยำ 100% พร้อมระบบจำลองขนาดจริง 1:1, จัดการสิทธิ์ผู้ใช้งาน (RBAC), ทิศทางการป้อนเช็คเข้าเครื่องพิมพ์, และระบบสรุปผู้บริหาร

---

## 🌟 จุดเด่นและความสามารถหลัก

1. **ระบบจัดทำเช็คด่วน (Easy Cheque Writer)**
   - คำนวณภาษีหัก ณ ที่จ่าย 1%, 2%, 3% อัตโนมัติ พร้อมแปลงยอดสุทธิเป็นตัวหนังสือภาษาไทย (Thai Baht Text) ถูกต้องตามหลักไวยากรณ์
   - สร้างใบสำคัญจ่าย (Payment Voucher) ประกอบฎีกาเบิกจ่ายได้ทันที

2. **ระบบจำลองเช็คขนาดจริง 100% (1:1 Physical Scale Simulation)**
   - แสดงผลตามมิลลิเมตรจริงบนหน้าจอ (241×90 มม. หรือขนาดตามธนาคาร)
   - ปรับขนาดฟอนต์ (Font Size) แยกแต่ละช่อง หรือปรับทั้งฉบับพร้อมกัน (±0.5 pt)
   - ไม้บรรทัดดิจิทัลและเส้นกากบาทช่วยทาบตำแหน่งพิกัด (X, Y)

3. **ระบบแบบอักษรเอกภาพ 100% (Cheque Typography Unification)**
   - ใช้ฟอนต์เดียวกันทั้งในหน้าจอตั้งค่าพิกัด, หน้าจำลองขนาดจริง 1:1, หน้าจอตัวอย่างก่อนพิมพ์ และการสั่งพิมพ์จริงบนกระดาษ
   - เลือกระหว่าง:
     - **TH Sarabun New / Sarabun** (มาตรฐานทางการราชการไทยและเช็คธนาคาร)
     - **Prompt** (โมเดิร์น ไร้หัว ทันสมัย)
     - **Noto Sans Thai** (มาตรฐานสากล คมชัดสูง)
     - **IBM Plex Sans Thai** (ชัดเจน เป็นทางการ)
     - **Cordia New / Angsana New** (ฟอนต์คลาสสิก Windows)

4. **ทิศทางการป้อนเช็คเข้าเครื่องพิมพ์ (Printer Feed Direction)**
   - กราฟิกจำลองช่องป้อนกระดาษเสมือนจริง พลิกหมุนตามทิศทางป้อน:
     - ↔ แนวนอนปกติ (สอดซ้าย 0°)
     - 🔄 แนวนอนกลับด้าน (สอดขวา 180°)
     - ⬆ แนวตั้ง (สอดหัวเข้า 90°)
     - ⬇ แนวตั้ง (สอดท้ายเข้า 270°)
   - สั่งพิมพ์จริงหมุนพิกัดตามทิศทางดึงกระดาษอัตโนมัติ

5. **ระบบการแบ่งระดับสิทธิ์ที่ชัดเจน (Role-Based Access Control - RBAC)**
   - **ADMIN (ผู้ดูแลระบบ):** จัดการผู้ใช้งานทั้งหมด (เพิ่ม/แก้ไขชื่อ/เปลี่ยนตำแหน่ง/รีเซ็ตรหัสผ่าน/เปลี่ยนสิทธิ์/ระงับการใช้งาน/ลบบัญชี), ลบประวัติเช็ค, จัดการแม่แบบธนาคาร, ดูสรุปผู้บริหาร
   - **USER (เจ้าหน้าที่ทั่วไป):** บันทึก เขียนเช็ค พิมพ์เช็ค ดูประวัติ แต่ไม่สามารถแก้ไขหรือเข้าถึงส่วนของผู้ดูแลระบบได้
   - การลงทะเบียนหน้าแรกจำกัดสิทธิ์เป็น USER อัตโนมัติ เพื่อป้องกันการเข้าถึงระดับ Admin โดยไม่ได้รับอนุญาต

6. **ระบบพิมพ์ทดสอบลงกระดาษ A4 (A4 Calibration Test Sheet)**
   - พิมพ์กรอบขนาดเช็คจริงลงบนกระดาษ A4 ธรรมดา เพื่อนำเช็คจริงมาทาบเทียบตำแหน่งกับแสงไฟก่อนพิมพ์จริง

---

## 🖨️ คำแนะนำการตั้งค่าในหน้าต่างพิมพ์ของเบราว์เซอร์ (Ctrl + P)

เพื่อให้ตัวอักษรพิมพ์ลงในช่องของเช็คจริงได้อย่างแม่นยำ 100%:
1. **ระยะขอบ (Margins):** เลือกเป็น **"ไม่มี" (None)**
2. **มาตราส่วน (Scale):** เลือกเป็น **"กำหนดเอง 100%" (Custom: 100%)**
3. **ส่วนหัวและส่วนท้าย (Headers & Footers):** **ปิด / ติ๊กถูกออก**

---

## 🚀 เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Lucide Icons
- **Fonts:** Google Fonts (Prompt, Sarabun, Noto Sans Thai, IBM Plex Sans Thai)
- **Local Database & Audit Trail:** LocalStorage Service พร้อมเก็บบันทึกประวัติการพิมพ์ (Print Logs) ย้อนหลัง
